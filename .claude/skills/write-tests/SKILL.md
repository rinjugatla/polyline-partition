# write-tests

テスト規約の本体は `AGENTS.md` の 5 章と仕様書 8 章にあり、このスキルはテストを書く手順を定める。

## 手順

1. 対象の仕様 ID（FR-xx、V-xx、E2E-xx）を特定し、仕様書の該当箇所を読む
2. ケースを「正常系」「異常系」「境界条件」に分けて列挙してから書き始める
   - 幾何処理では、退化ケース（零長線分、共線重なり、頂点が線分上、ε ちょうどの距離）を境界条件に必ず含める
3. 不具合の修正では、先に不具合を再現するテストを書き、失敗を確認してから修正
4. 次の形式で書く
   - `describe` を 3 階層（対象 → 観点 → 条件）にし、`it` と合わせて日本語で記述
   - AAA（準備・実行・検証）の順で、1 テスト 1 ケース
   - 数値は定数に名前を付け、マジックナンバーを避ける
   - 乱数は固定シードにする
   - 座標の比較は `toBe` ではなく ε を使った比較にする
   - ε は関数への引数として渡す
5. ファイル配置は実装と同じ階層名の `*.test.ts`（E2E は `e2e/`）
6. `pnpm test`（E2E は `pnpm test:e2e`）を実行して通過を確認する
